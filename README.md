An entry for make.fun's [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) bounty: the one line a smart fridge would text its owner at 3am — a small-voiced machine with an opinion and no shame about sharing it, fresh angle (not milk, ice, or a door left open), punchline in the last words.

`main.py` (Python 3, stdlib only) writes the line to `/output/entry.txt`, deterministically, via a temp file plus rename with mode 644.
